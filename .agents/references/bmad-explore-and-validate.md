# BMAD Explore and Validate - Project Reference

Source:
https://docs.bmad-method.org/plan/explore-and-validate-an-idea/

Applied to the Assignment documentation:
1. Start from the actual problem, not from a preferred technology.
2. Clarify the product idea and the primary users before defining features.
3. Pressure-test vague assumptions and keep only decisions that matter to the assignment.
4. Condense research into a small set of durable project decisions.
5. For an existing project, treat the real codebase and project files as the source of truth.

For Longevity Diet Companion this becomes:
Context -> Problems -> Solutions -> Main Actors -> Main Features -> Architecture -> Technology -> Data Model.

We intentionally do not vendor the full BMAD documentation site into this repository to keep the project clean.
