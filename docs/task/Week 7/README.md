# Week 7 - Product Integration & UX Quality

## Mục tiêu tuần
Tích hợp toàn bộ module thành một product flow thống nhất, responsive, accessible và có UX state nhất quán.

## Phân công
| Task | Owner | Reviewer |
|---|---|---|
| Task 1 - Application Shell, Navigation & Role-Aware Integration | Thành viên 1 | Thành viên 3 |
| Task 2 - Design System, Responsive & Accessibility Hardening | Thành viên 2 | Thành viên 4 |
| Task 3 - Unified Validation, Error/Empty/Loading UX | Thành viên 3 | Thành viên 1 |
| Task 4 - Frontend State, Performance & Usability Regression | Thành viên 4 | Thành viên 2 |

## Nguyên tắc
- Không tạo feature domain mới nếu không phải blocker.
- Ưu tiên consistency và usability.
- Mock data phải được loại khỏi production paths.
- Accessibility được kiểm tra bằng keyboard/focus/semantics, không chỉ màu sắc.

## Exit criteria
- Main user journeys liền mạch.
- Role-aware navigation đúng.
- Responsive/mobile pass.
- Error/loading/empty states nhất quán.
- Frontend build/performance/regression pass.
