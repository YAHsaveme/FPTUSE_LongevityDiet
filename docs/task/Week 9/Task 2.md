# Task 2 - PRN232 Evidence, Traceability & Grading Coverage

**Owner:** Thành viên 2  
**Reviewer:** Thành viên 4  
**Branch:** `docs/w9-prn232-evidence`

## Mục tiêu
Chứng minh từng rubric item bằng implementation/evidence cụ thể, không chỉ viết trong tài liệu.

## Coverage cần xác minh
- architecture/layering;
- REST API + CRUD;
- search/filter/sort/pagination;
- JWT;
- background processing;
- Redis message broker producer/consumer;
- gRPC independent service;
- Docker/container deployment;
- Swagger/OpenAPI;
- DB migration/seed;
- README/setup;
- team responsibilities;
- E2E demo.

## Evidence format
Mỗi requirement map tới:
- code location;
- endpoint/service;
- diagram;
- test;
- runtime/demo step.

## Audit
- Không claim feature chưa implement.
- Link/file path phải tồn tại.
- Diagram phải khớp implementation cuối.
- README command phải chạy được.
- Port/service name phải đúng.

## Deliverables
- Final traceability matrix.
- Rubric checklist.
- Evidence index.
- Missing-item blocker list nếu còn.

## Definition of Done
Reviewer có thể đi từng dòng rubric và tìm được code/test/demo evidence tương ứng mà không đoán.
