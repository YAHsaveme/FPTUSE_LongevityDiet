# Week 9 - Stabilization, Evidence & Final Presentation

## Mục tiêu tuần
**Feature freeze.** Không thêm feature mới. Tập trung sửa bug, xác minh PRN232 coverage, rehearsal và đóng gói submission cuối.

## Phân công
| Task | Owner | Reviewer |
|---|---|---|
| Task 1 - Critical Bug Fixing & Security Regression | Thành viên 1 | Thành viên 3 |
| Task 2 - PRN232 Evidence, Traceability & Grading Coverage | Thành viên 2 | Thành viên 4 |
| Task 3 - Demo Data, Demo Script & Failure-Recovery Rehearsal | Thành viên 3 | Thành viên 1 |
| Task 4 - Final Documentation, Architecture Defense & Submission Integrity | Thành viên 4 | Thành viên 2 |

## Feature freeze rules
- Chỉ sửa defect, security, reliability, demo blocker.
- Không refactor lớn nếu không có defect/evidence.
- Không đổi architecture sát deadline trừ khi bắt buộc.
- Mọi fix phải chạy regression liên quan.

## Exit criteria
- Zero known critical blocker.
- Mandatory PRN232 evidence đầy đủ.
- Demo rehearsal pass.
- Submission package build/run được.
