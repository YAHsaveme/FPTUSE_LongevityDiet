## Mục tiêu tuần
Tách FMD thành module education/safety riêng, có state machine và professional-review gate; đồng thời hoàn thiện governance cho rule/version/audit.

## Safety principles
- Không chẩn đoán.
- Không kê thuốc.
- Không tự tạo therapeutic fasting protocol.
- High-risk case phải dừng ở education/professional review.
- FMD không được nhập chung vào normal meal planner.

## Exit criteria
- Safety state machine được enforce ở backend.
- High-risk user không thể tự tạo cycle.
- Rule publish có version/audit.
- Admin review/audit truy vết được.
